# Roadmap

## v0.1.0

Instruction-only Codex plugin with DevOps/MLOps skills, focused references, sample Obsidian-style notes, and sample generated outputs.

## v0.2.0

Implemented Markdown and Obsidian context exporter that can compile selected notes into Codex-ready context briefs and AGENTS.md drafts.

## v0.3.0

Implemented local runbook generator for turning structured Markdown or Obsidian-style notes into practical operational runbooks.

## v0.4.0

Implemented local Terraform and Kubernetes static review helper for common review and triage checks.

## v0.5.0

Optional MCP integration for controlled access to compiled context, runbook indexes, and local knowledge sources.

## v1.0.0

Stable release with documented workflows, tested exporters, clear upgrade guidance, and production-quality examples.
